⚛️ How this connects to quantum optimization▼

This puzzle is an optimization analogy: many legal move sequences can reach the same final arrangement, but some use fewer operations. That is the idea to notice before moving into more formal quantum optimization methods.

1 · Same goalDifferent valid sequences can produce the same final result.

3 · Optimization mindsetSearch for a lower-cost sequence instead of stopping at the first valid solution.

Note: This container game is a teaching analogy, not a simulation of superposition or entanglement.

How to play

Container Stack Shuffle

Pick the top box, move it, and match each Dispatch target.

🎯 1. Read the Target

Each Dispatch heading shows a compact Target sequence. Read it from left to right as bottom → top.

👆 2. Pick only the top container

The small ▲ marks the exposed container you are allowed to move.

✨ 3. Choose a glowing destination

After selecting a container, available stacks glow. Click one of them to place the container.

🧩 4. Use Buffer A/B temporarily

Buffers are workspace only. To finish, every Dispatch must match its Target and both buffers must be empty.
